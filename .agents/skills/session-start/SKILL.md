# Session Start

## Instructions

1. Read `AGENT.md` in the repo root completely.
2. Read `BUILDLOG.md` in the repo root. Understand what has already been built and what was left as next steps.
3. Confirm to the user with one short message: what phase the project is in, and what the last completed task was according to the build log.
4. Wait for the user to give a task brief. Do not start anything until it is given.
